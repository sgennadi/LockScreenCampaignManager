# Exact-principal AD timer source ranking

Unified GPO readiness joins supported timer source settings with the exact computer and optional user scope by GPO GUID and policy half, rather than relying on the initial inventory's coarse selected-OU risk. This keeps early display, sleep, inactivity or RDS timers visible when exact AD projection reveals a link outside the initial inventory scope.

Fresh complete evidence can rank supported Registry.pol timer sources and security-template inactivity sources by AD link priority. Ties, WMI/ACL uncertainty, mixed CSEs, GPP or unconfirmed user loopback remain unresolved. The report compares the selected machine timer against the projected enabled user Screen Saver timer where available, otherwise the configured campaign timer. Zero means disabled/never for the individual machine timer. Existing named-blocker and endpoint comparisons remain.

This is a read-only estimate over recognized inventory values, not endpoint RSoP, proof of registry type, visual state, active power plan, site applicability or actual Screen Saver operation. No policies or endpoints are changed.
