# Управление существующей GPO и немедленный запуск — 0.3.0-preview.1

1. Открой AD / GPO Deploy, подключись к нужному домену, выбери DC, OU, группу компьютеров.
2. Нажми **Управление GPO / конфликты / Push Now**.
3. Вкладка GPO: выбери только ту GPO, в которой обнаружен наш агент и корректный campaign.json.
4. **Disable** отключает ссылку на выбранной OU. Объект GPO и файлы SYSVOL сохраняются. Уже запущенные локальные задания на ПК **не прекращаются автоматически**.
5. **Enable** включает прежнюю ссылку. Если календарь уже завершился, используй **Reuse** с новым расписанием и новым campaignId.
6. **Unlink** удаляет только ссылку на выбранной OU; **Delete** окончательно удаляет управляемую GPO, только если нет ссылок в домене. Исходный пакет SYSVOL удаляется отдельно после проверки. Удаление требует ручного ввода GUID.
7. **Reuse** заменяет ссылку Startup-скрипта, копирует новую кампанию, обновляет версии в AD/SYSVOL, сохраняя GUID и Security Filtering. Только после окончания старой кампании. Старый пакет сохраняется для аудита.
8. Вкладка **Поиск конфликтов**: ищет активные и неактивные Registry.pol и GPP Registry.xml по OU и предкам, учитывает Block Inheritance, Enforced и отключённые ссылки. Дополнительно, при наличии прав, читает HKLM одного компьютера через Remote Registry. Это индикаторы конфликтов, **не полный RSoP**: WMI, AD ACL, Site GPO, GPP targeting и локальные политики надо проверять через gpresult на целевой машине.
9. Вкладка **Запуск сразу на ПК**: читает список компьютеров, находящихся одновременно в OU и выбранной группе (включая вложенные). Выбери не более 25 ПК, проверь Preview, затем введи GUID GPO и подтверди. Remote Task Scheduler COM запускает временное задание SYSTEM с параметром `-Mode Install`. Потребуются RPC, firewall и права локального администратора. WinRM/RSAT не используются.
10. **Push** немедленно устанавливает/синхронизирует агент, но до даты начала изображение НЕ показывается. **Cleanup** запускает удалённую очистку только выбранных ПК. Отдельное локальное расписание остаётся для обычных GPO Startup на выключенных машинах.

ВНИМАНИЕ: не применяй в продуктивном AD до проверки создания, Disable/Enable, Reuse, Delete и Push на изолированной тестовой OU. Авторизованные изменения AD и SYSVOL могут частично завершиться; приложение выводит GUID и пути для ручного устранения.
