# English / Hebrew / Russian interface — iterative localization (Preview.97)

**Preview.103:** AD Deployment and Group assignments now translate OU-first/Group-first, separate User/Computer target labels, LDAP direct-membership warnings and Save/Preview guidance into Russian and Hebrew. Selected LDAP DN/GUID/OU and policy keys never change with language. Group assignments provides auto-wrapping warnings for 200% DPI; actual physical Windows 10/11 RTL inspection remains required (#36). [Targeting guide](OU-AND-SECURITY-GROUP-TARGETING.md).

Use **Settings → Language → English / עברית (Hebrew) / Русский → Apply**. Language is stored in the existing per-user `ui-settings.json` beside density, UI scale and font size. No AD privileges, additional installation or language packs are required.

**Covered in Preview.90:** most primary navigation buttons, menu labels, Wizard actions, Settings, key software-update controls, GPO Operations tabs, and the Local Lab Evidence viewer. Main windows use WinForms RTL mirroring. Technical text/values (UNC, LDAP, GPO GUID, logs, JSON, machine names, hashes, report summary) stay LTR to avoid corrupting their perceived order.

**Expanded in Preview.91:** The seven-step Campaign Wizard now translates main headings and explanations, step rail, live navigation, Screen Saver mode options and common status, and Save/Deploy SYSVOL-vs-SMB selection. Mode enums and SYSVOL/SMB ComboBox items retain their original values internally; only the visible captions are localized. Wrapped text rows grow within a scrollable wizard page; the bottom navigation bar remains separate.

**Expanded in Preview.92:** the AD Connection Wizard, alternate user/password search, AD/GPO deployment steps, SYSVOL/SMB and PS1/EXE selection labels, Client Health summary/header and SMB feedback controls have Hebrew captions. Internal enum values and client report CSV/JSON keys remain English. Application title captions preserve the version and company name; technical identities and evidence remain left-to-right. All six simulated DPI/font profiles exercise Hebrew → English reversal without changing data or talking to AD.

**Expanded in Preview.93:** GPO Operations now includes more Hebrew titles, actions and hints for agent management, deferred repairs, gMSA repair worker and static GPO conflict findings. Diagnostics review, local trend analysis and privacy confirmation are more readable in Hebrew. GUI-only ComboBox formatting and grid header translation never modify selected operation IDs, AD activity filters, risk/queue states, JSON/CSV report schemas or GUID confirmation input. Six simulated font/DPI profiles check a reversible English/Hebrew switch.

**Expanded in Preview.94:** Russian now joins English and Hebrew in the per-user language selector. The main editor, campaign wizard, AD/GPO, Client Health, diagnostics, schedule and major advanced windows gain Russian display strings; Hebrew is expanded through the dedicated schedule editor, company profiles, assignment matrix and history/advanced views. An original English per-control caption is retained for reliable Russian ↔ Hebrew ↔ English switching, including dynamically changed schedule table headers. Never translate actual enum/ComboBox item values or JSON/report data.

**Expanded in Preview.95:** Native gMSA 24/7 setup/readiness, SMB Client Health/alert settings and Device & Repair Dashboard now have reversible Russian and Hebrew captions, consent warnings, local status text and table headers. Protected queues, RPC/GPO commands, verified scopes, diagnostic payloads and exported readiness JSON remain unchanged. CI exercises six simulated 100–200% font/scale profiles with all three languages; real Windows 10/11 interactive RTL and visual QA are still required.

**Expanded in Preview.96:** The Updater and local Windows Lab Evidence viewer now include Russian and Hebrew status, verification, rollback and safety/consent messages. UI-only release-channel text can be translated without changing original ComboBox items. SHA-256, version, URLs, package files, passwords, local JSON/technical results and raw GitHub Release notes are not translated. Six simulated scaling profiles check three-language switching; real 200% Windows visual acceptance remains open.

**Expanded in Preview.97:** Client Health SMB/Repair and final-report confirmation, read-only gpresult XML/HKLM verification warnings, privacy-sensitive GPO/closure CSV exports, campaign inventory and GPO status descriptions now include Russian and Hebrew display strings. Technical data, report evidence and commands remain canonical English. Existing approval defaults and GPO GUID confirmations remain unmodified. Six simulated 100–200% layouts test three-language reversibility; live Windows display acceptance remains open.

**Preview.102:** Native Tools / Help visual-DPI acceptance adds 25 English/Russian/Hebrew UI strings and reversible labels. The report records only anonymous operator checks and DPI; it does not prove real physical RTL or GPO applicability. [Run the interactive visual checklist](WINDOWS-200-DPI-VISUAL-CHECK.md). The issue remains open pending real Windows acceptance.

**Partial translation by design:** some advanced AD/GPO dialogs, validation details, raw diagnostic evidence, settings/status subdialogs, some Client Health text and additional dynamic status messages remain English. English and Hebrew are not yet 100% complete, nor is Russian. JPG photo saver deployment still requires real Windows/AD pilot acceptance. A missing translation is displayed in English rather than being silently changed. Restart/reopen a dialog after changing language if a status was generated before the switch.

English is the default. Switching back to English is reversible. This setting changes **UI presentation only**, not campaign schedules, timezone IDs, serialized JSON, agent package structure, Active Directory, GPO behavior or shell script output.

Real interactive 200% DPI/RTL visual testing is recommended in addition to the six offline font-scale profiles used by CI.
