# Smart image-folder import — 0.4.0-preview.15

## Последовательность

1. **Companies** → выбери организацию → **New campaign**.
2. Выбери дату/время старта, часовой пояс, затем **Schedule**.
3. Выбери **Every day / Work days / Custom weekdays / Specific dates /
   Every N hours/minutes**. Для нового интервального режима введи часы
   и минуты (например, 2 h 30 min = 02:30).
4. Нажми **Import image folder...** → **Choose folder...** и укажи
   каталог изображений.
5. Появится таблица для проверки **Scheduled day/time / Image /
   Matching explanation**. В ней можно вручную исправить соответствие.
6. Нажми **Apply image mapping**, затем **Apply schedule**,
   **Validate**, **Save project**. Экспорт или AD/GPO deployment по-прежнему
   требует отдельного подтверждения.

Поддерживаются файлы JPG, JPEG, PNG, BMP; читаются только файлы верхнего
уровня выбранной папки, максимум 30 изображений. Файлы и их имена не
изменяются. Символические ссылки и пустые файлы не импортируются.

## Что программа распознаёт

| Имя | Подсказка |
| --- | --- |
| Monday.jpg / Mon_01.jpg | Понедельник, первый слот |
| Tue_02.png / friday.jpg | Вторник/пятница |
| пн.png / среда_03.bmp | Русские дни недели |
| יום_שני_03.jpg / שבת.png | Иврит, понедельник/суббота |
| slide_01.jpg / 02.jpg | Номер в расписании |
| 2026-11-09.jpg / 09.11.2026.png | Конкретная дата |

Программа сопоставляет **расписание, созданное до выбора папки**,
с подсказками имени, а не угадывает часы из случайных чисел в имени
файла. Уникальное совпадение дня/номера/даты может быть предварительно
выбрано. Если в файле противоречивые слова, несколько изображений
претендуют на один слот или соответствия нет, строка остаётся без
выбранного изображения.

**Без явной проверки неоднозначные изображения не назначаются.**
Используй выпадающий список для выбора, подтверди ручную проверку
и только затем нажми Apply. Одно физическое изображение в ходе одного
импорта не дублируется; для повторного показа используй
**Repeat selected image** в календаре.

В режиме **Specific dates**, если во всех файлах есть уникальные
распознаваемые даты и проект пока не имеет отдельного расписания,
программа предлагает даты из имён с сохранением выбранного времени
старта. Даты сортируются вместе с картинками.

## Every N hours/minutes

При старте 09.11.2026 в 08:35 и интервале 02:30 смены назначаются
на 08:35, 11:05, 13:35, 16:05 ... Интервал считается по реальному
прошедшему времени, а не по циклу с полуночи. При переходе времени
проверяются недопустимые/неоднозначные часы DST. Предварительные
\`atLocal\` значения попадают в существующий проверенный
\`campaign.json\`, поэтому клиенту не нужен новый формат GPO.

Последняя картинка показывается заданное **Last slide (hours)**,
затем клиент пытается вернуть прежнюю настройку экрана блокировки.

## Безопасность

Импорт картинок и настройка расписания полностью локальны; они не
создают GPO, не редактируют AD-группы и не передают пользовательские
данные в GitHub. Проверки исходных изображений и SHA-256 при экспорте,
проверка manifest/agent на клиентах и политика восстановления
сохраняются.


## Проверка имён в preview.14

Если имя файла содержит две даты (например, `2026-11-09_2026-11-10.jpg`) или несуществующую дату (например, `2026-02-30.jpg`), соответствие не подставляется автоматически и требует ручного выбора. Если одновременно указаны день, дата и порядковый номер, все распознанные значения должны совпасть с выбранным слотом: `Monday_02_2026-11-09.jpg` не будет автоматически назначено первым изображением, несмотря на совпадающие дату и день.

## Неоднозначные дни и даты в preview.15

Имя `Monday.jpg` или `2026-11-09.jpg` больше не подставляется автоматически, если в выбранном расписании есть несколько смен изображений в этот понедельник или в эту дату. Это бывает при **Every N hours/minutes** и многонедельных кампаниях. Имена `Monday_01.jpg` и `slide_06.jpg` с однозначной нумерацией могут быть назначены автоматически. Неоднозначные подсказки не скрывают однозначные совпадения других файлов. Для оставшихся строк выбери изображение вручную, проверь его и подтверди Apply. Дополнительные подсказки не меняют исходные имена файлов, а оставшиеся пробелы в назначении требуют явной проверки перед Apply.
