# LockScreen Campaign Manager 0.4.0-preview.73

## User Screen Saver GPO binary fix

**Do not deploy Screen Saver with preview.72 in production.** Its User/Registry.pol wrote registry key/value names without mandatory UTF-16LE NUL terminators (MS-GPREG), potentially causing Windows to reject the policy.

Preview.73 fixes the binary format, checks both generated bytes and SYSVOL readback through an independent parser before linking, and updates User GPT.INI version without merging adjacent lines. Self-tests include intentional corruption and approval mismatch.

The new Screen Saver still selects built-in Windows .scr; JPEG campaign slides remain Lock Screen only. The multi-group OU/group selection is unchanged. First verify an isolated user OU/security group with gpresult /h and local HKCU effective settings. Hosted CI does not reach your AD.

[Microsoft MS-GPREG](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-gpreg/5c092c22-bf6b-4e7f-b180-b20743d368f5).
