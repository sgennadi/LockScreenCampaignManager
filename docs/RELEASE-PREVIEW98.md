# LockScreen Campaign Manager — 0.4.0-preview.98

## What's new

1. **Readable release notes:** What's New now appears as a short numbered list instead of raw GitHub Markdown.
2. **Cleaner Updater:** Changes appear first; the installed version, update package and SHA-256 remain visible below.
3. **Update indicator:** Its tooltip uses a brief numbered summary without Markdown symbols or raw links.
4. **English / Русский / עברית:** The What's New heading and empty-state message follow the chosen interface language.
5. **Regression coverage:** Offline checks cover numbered lists, older paragraph-based releases, links, long notes and absent release notes.

**Safety and compatibility:** Release notes are display-only and are not interpreted as commands. The full release text is available through **Open releases**. Existing manual installation approval, architecture checks, hash verification and rollback behavior are unchanged. Windows x86/x64 builds and offline self-tests must pass before publication. Real Windows 10/11 200% DPI/RTL, live SMB LocalSystem and JPG Screen Saver User GPO acceptance remain open (#36, #30, #25/#26).
