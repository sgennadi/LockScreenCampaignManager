# Сохранение размеров и положения окон — LockScreen Campaign Manager

В версии **0.4.0-preview.8** приложение сохраняет позицию/размер основных
окон управления: GPO Operations, Domain Deployment, gMSA Setup,
Production Readiness, UniversalUpdater, Diagnostics, Error Trends,
Campaign History, Client Feedback settings, UI settings и Alerts.

Положение сохраняется при обычном закрытии каждого окна и
восстанавливается при следующем открытии. При подключении/отключении
дисплея, смене разрешения или DPI устаревшие координаты ограничиваются
**видимой рабочей областью монитора**; окно не должно оказаться целиком
за границей экрана. Для окон, поддерживающих разворачивание,
сохраняется Maximized. Новые значения DPI учитываются в размере окна.

Файл настроек:
\`%LOCALAPPDATA%\LockScreenCampaignManager\ui-window-placement.json\`.

В нём только ID окна, координаты, размеры, DPI и maximized.
Не сохраняются OU, домен, gMSA, пароли, имена компьютеров или отчёты.
Файл ограничен 32 KiB; некорректные, повреждённые и reparse-point
файлы игнорируются. Никакие данные не отправляются в сеть.

Основной главный экран сохраняет свои размеры и положение через
имеющийся ранее механизм. Отдельная новая реализация его не дублирует.

WinForms автоматически масштабирует интерфейс по DPI. Наш общий
UiStyle применяет Segoe UI, Windows-цвета и пользовательский UI Scale /
Font Scale. Для проверки GUI отдельно нужны ручные тесты при DPI
100%, 125%, 150% и 200% с уменьшением/увеличением окон — CI проверяет
правильность расчёта координат, но не заменяет визуальный осмотр Windows.


## Автоматическая проверка GUI в preview.10

В GitHub Actions после обычных SelfTests запускается `--ui-smoke-test` на Windows x86/x64. В тестовом процессе создаются, но не показываются на экране, окна Updates, Production Readiness, Diagnostics и Error Trends; проверяются кнопки, геометрия и результаты восстановления окна на воображаемом экране 1440×900. Дополнительные масштабы шрифта 100%, 125%, 150% и 187,5% не меняют сохранённые настройки пользователя. Тест не подключается к AD, не меняет GPO или задания gMSA.

**Ограничение:** это проверка построения WinForms и некоторых элементов, а не визуальный тест настоящего DPI 200%. Для окончательной приёмки нужно запустить EXE в интерактивной Windows VM с DPI 100/125/150/200%, проверить заголовки, toolbar, поля и все вкладки, после чего сохранить скриншоты.
